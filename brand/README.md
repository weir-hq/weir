# Weir brand

The mark is a **V-notch weir**: the plate hydrologists put across a stream to measure its flow.
The height of the water in the notch gives the flow rate, which is what Weir does for
pipelines. The two halves of the plate also read as a W.

| File | Use |
|---|---|
| `weir-mark.svg` | The mark, rounded square. Website, docs, slides. |
| `weir-avatar.svg`, `png/weir-avatar-512.png` | Square edge to edge, for avatars that round the corners themselves (GitHub org, social) |
| `weir-mark-mono.svg` | One color on transparent, color from CSS `color`. Print, stickers, monochrome places. |
| `png/weir-mark-512.png` | The mark as PNG |
| `png/weir-logo-light.png`, `png/weir-logo-dark.png` | Mark + "Weir", for light and dark backgrounds |
| `png/apple-touch-icon.png`, `png/favicon-32.png` | Browser and phone icons |

## Colors

| Name | Hex | Where |
|---|---|---|
| Weir teal | `#0b6b73` | The mark's background, links, accents (light mode) |
| Bright teal | `#5ccfc6` | Accents in dark mode |
| Water | `#9fe7e3` | The water in the notch and the wave |
| Ink | `#16191d` | Text on light |
| Paper | `#fbfbf9` | Background on light |

The wordmark is set in the system UI font (SF Pro, Segoe UI, Roboto), bold, −2% letter
spacing. The PNG lockups were rendered with SF Pro. Before printing or a proper brand
launch, pick a licensed typeface and convert the wordmark to outlines.
