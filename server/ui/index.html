WeirQL reference 
function( {label="value", label=~"regex", label!="x"} [range] [, param] ) [by (label, ...)]
FunctionReturnsWhat it answers
graph({...}[5m])graphStages and edges with rate, age, in-flight, and losses. Red = items vanished/errored or unaccounted; amber = old in-flight items or retries. Edges show what is waiting on them (needs the scraper), amber when the oldest waiting item is unusually old.
leak({...}[5m])tableConservation per stage: in = passed + done + dropped + vanished + errored + Δin_flight. Anything else is unaccounted. queue_growth = emitted − received downstream: how much the backlog between this stage and the next grew.
drops({...}[1h]) by (reason)tableWhy items did not pass: explicit drop reasons, vanished, errored.
decompose({...}[15m])tableWhere end-to-end age comes from: waiting before each stage vs time inside it.
age({...}, 0.99)seriesAge of items (now − origin event time) when they leave each stage, at a quantile.
oldest({...})seriesAge of the oldest item still in flight in each stage — the "is anything stuck" signal.
in_flight({...})seriesItems received but not yet closed.
throughput({...})seriesItems entering each stage per second.
lost({...})seriesItems vanished or errored per second.
transit({...}[15m])tablePer edge, from the scraper: items waiting between two stages now, how old the oldest is, and unaccounted = sent − received − growth of waiting: items lost in between.
waiting({...})seriesItems waiting on each edge (in a topic or staging table), over time.
oldest_waiting({...})seriesAge of the oldest item waiting on each edge. Climbs while a consumer or cron is stopped.

Labels: pipeline, stage. Series functions use the time range picker; table and graph functions use [range] if given.
